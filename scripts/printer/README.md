# 삼성 SL-C513W 프린터 안정화 스크립트 (macOS)

`fix_printer.sh`: 삼성 전용 드라이버 대신 macOS 기본 기능인 AirPrint로 프린터를 다시 등록합니다. 오류가 나도 프린터가 "멈춤" 상태로 남지 않게 설정합니다.

## 왜 이렇게 하나요

- 삼성 프린터 사업은 HP로 넘어갔고, Mac용 삼성 드라이버는 최신 macOS와 Apple 칩에 맞춰 관리되지 않고 있습니다.
- AirPrint는 macOS에 처음부터 들어 있어서 별도 드라이버가 필요 없고, macOS 업데이트 후에도 잘 깨지지 않습니다.
- IP 주소 대신 프린터 이름(`.local`)으로 연결하므로 공유기가 IP를 바꿔도 계속 연결됩니다.
- 오류가 나면 기본 설정은 프린터를 멈춰 버립니다(화면의 "오류" 상태). 이 스크립트는 멈추는 대신 다시 시도하도록 바꿉니다.

## 사용 방법 (Mac의 "터미널" 앱)

```
cd 이_폴더_경로
./fix_printer.sh check          # 1단계: 현재 상태 확인 (아무것도 바꾸지 않음)
./fix_printer.sh setup          # 2단계: 다시 등록 (관리자 암호 필요)
./fix_printer.sh test           # 3단계: 시험 인쇄
./fix_printer.sh watchdog-on    # 선택: 2분마다 자동 복구
```

- 자동 검색이 안 되면 IP를 직접 넣습니다: `./fix_printer.sh setup 192.168.0.201`
- 자동 복구 끄기: `./fix_printer.sh watchdog-off`

## 주의

- `setup`은 같은 프린터로 등록된 기존 항목(삼성 드라이버 항목, IP 항목)을 지우고 새로 등록합니다. Sindoh 등 다른 프린터는 건드리지 않습니다.
- 자동 복구는 멈춘 프린터를 다시 켜기만 하고 인쇄 작업은 지우지 않습니다.
- Linux 환경에서 문법 검사만 했고, 실제 Mac에서는 아직 실행해 보지 않았습니다.
