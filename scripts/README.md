# 허브-위키 자동 연결 스크립트

`link_hub_wiki.py`: `06_MOC` 허브와 `07_QONE_Wiki/03_Wiki` 위키 페이지를 문자열 비교만으로 서로 연결합니다. AI는 쓰지 않습니다.

## 실행 (Python 3.9 이상, 추가 설치 필요 없음)

```
python link_hub_wiki.py "보관함경로"           # 1단계: 미리보기 (파일을 바꾸지 않음)
python link_hub_wiki.py "보관함경로" --apply   # 2단계: 실제 적용
```

## 규칙

- 짝 찾기: 허브 파일명에서 " 허브" 앞부분(예: `벽지 허브 - Drive - 2026` -> `벽지`)을 위키의 파일명, title, aliases, counterparty, tags와 비교합니다. 띄어쓰기, 기호, (주)/㈜ 같은 회사 표기는 무시합니다.
  - 완전히 같으면 링크를 답니다.
  - 일부만 겹치면(예: `벽지` ~ `벽지시공`) 링크하지 않고 점검 파일에만 남깁니다.
- 허브: 프론트매터 바로 아래에 `## 정리된 위키 페이지` 절을 추가합니다. 허브당 최대 20개이고, 회사 페이지가 먼저, 그다음 주제 페이지입니다.
- 위키(회사·주제 페이지): 맨 아래에 `## 원본 허브` 절을 추가합니다.
  - 회사/주제 구분은 프론트매터 `type`(company/회사, topic/주제) 또는 폴더 이름으로 합니다.
- 안전 장치
  - 수정 전 원본을 보관함 바깥 `<보관함>_backup_<시각>` 폴더에 복사합니다.
  - 추가만 하고, 지우거나 바꾸지 않습니다.
  - `02_Raw`는 수정하지 않습니다.
  - 제한 노트(`restricted: true`, 태그나 경로에 제한/기밀/restricted 표시)는 수정도 링크도 하지 않습니다.
  - 같은 링크가 이미 있으면 다시 넣지 않으므로 여러 번 실행해도 됩니다.
- 결과
  - `07_QONE_Wiki/점검_허브위키_애매한짝_<시각>.md`에 애매한 짝을 남깁니다.
  - `log.md`(`07_QONE_Wiki/log.md`, 없으면 보관함 맨 위 `log.md`)에 링크 수를 기록합니다.

## consolidate_cheonggiwa.py — 제주청기와장어 자료 취합·정리

바탕화면·문서·다운로드에서 이름에 `청기와`가 들어간 파일/폴더를 바탕화면의
`[ultimate] 제주청기와장어` 폴더로 모으고, 중복 파일(내용 동일)·빈 폴더·의미 없는 파일을 정리합니다.
Windows/macOS 모두 Python 3만 있으면 동작합니다.

```bash
python consolidate_cheonggiwa.py            # 미리보기 (변경 없음)
python consolidate_cheonggiwa.py --apply    # 실행
```

- 삭제 대상은 바탕화면 `_청기와정리_삭제대기_<날짜>` 폴더로 옮겨지며, 확인 후 직접 비우면 됩니다 (`--permanent`로 즉시 삭제).
- `--keyword 장어` 로 키워드 추가, `--root "D:/자료"` 로 검색 위치 지정, `--sweep-empty` 로 관련 없는 빈 폴더까지 삭제.
- 작업 내역은 대상 폴더 안 `_정리기록_<날짜>.csv` 에 남습니다.
